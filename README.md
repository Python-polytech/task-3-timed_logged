Декоратор timed_logged
=

Программа находит диапозон чисел, которые в CPython хранятся в закешированном виде.
1. Клонирование репозитория

```bash
git clone https://github.com/Python-polytech/task-3-timed_logged.git
cd task-3-timed_logged
```
2. Создание и запуск виртуального окружения
Для Windows:

```bash
# Создание окружения
python -m venv venv
# Активация окружения
.\venv\Scripts\activate
```
Для macOS и Linux:

```bash
# Создание окружения
python3 -m venv venv
# Активация окружения
source venv/bin/activate
```
Запуск

В директории task-3-timed_loggedn/ выполнить команду

```bash
python lab3.py
```

После запуска программы с заменой своей функцией функции-примера slow_sum в консоль будет выведен результат функции с логированием.
